# Attendance visual system

Microsoft Fluent 2 adapted to the existing PHP application. Reference: https://fluent2.microsoft.design/typography and https://fluent2.microsoft.design/layout.

Segoe UI typography, 14/20 body, 24/32 page titles, 16/22 section headings.
Neutral white and gray work surfaces; green workforce accent and dark green suite bar.
4px control corners; 32px controls; 36px navigation rows; 4px spacing rhythm.
Grouped left navigation, compact command/filter bars, flat data tables and a single segmented daily summary. Reserve color for actions and status, with text labels.
No decorative gradients, large colored metric cards, or excessive shadows.
Native accessible controls, visible keyboard focus, skip link, current-page navigation, reduced-motion support. Narrow screens use scrolling navigation and table containers.
This is a Fluent-styled native HTML implementation, not the Fluent React library.
